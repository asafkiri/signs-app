# שלטים — signs-app

אפליקציה עצמאית בעברית (RTL), מותאמת לנייד, להכנת שלטי מבצע לחנות ולרחוב. אתר סטטי, ללא Firebase, ללא AI וללא שליחת מחירי קנייה לשרת.

## שימוש

1. בוחרים **שלטי חנות** או **שלטי חוץ** ומזינים כותרת.
2. **המבצע כבר ידוע לי**: מחיר ליחידה, כמות במחיר (למשל 2 ב־20), או טקסט חופשי.
3. לחלופין, **חישוב לפי מחיר קנייה**: מחיר קנייה סופי ליחידת מכירה לפני מע״מ, שיעור מע״מ ורווח גולמי רצוי. בחירת המלצה ממלאת את השלט; שינוי עלות אינו מחליף את המחיר הנבחר בשקט.
4. בשלטי חוץ בוחרים אחת מ־7 תבניות. כולן ללא תמונות ובשחור־לבן.
5. שומרים שלטים לרשימה, מסמנים ומדפיסים, מורידים PDF או משתפים PDF בדפדפן שתומך בכך.

### פריסות

שלטי חנות: **4 בדף, 2 קטן, 2 גדול, 1 לרוחב**. כמו הכיוון שנבדק ב־yotvata-app: כותרת, מחיר גדול, מחיר קודם/הערה/תוקף אופציונליים. 2 קטן הוא 88% מהדף הרגיל, ממורכז. גם שלושה שלטים מותרים: האחרון מופיע בדף הבא, ללא אובדן שלט.

שלטי חוץ: תמיד A4 לרוחב, תבניות מסגרת קלאסית / כותרת שחורה / כוכב / כרטיס / אלגנטי / חצי־חצי / מחיר בבמה. זהו מימוש עצמאי ולא העתקה מלאה של האפליקציה האחרת. העיצוב נבנה בקוד; אינו דורש תמונות או גופנים להורדה.

### חישוב המחיר

`עלות כולל מע״מ = עלות לפני מע״מ × (1 + מע״מ / 100)`

`מחיר המבצע כולל מע״מ = עלות כולל מע״מ × כמות / (1 - אחוז הרווח / 100)`

אחוז רווח הוא **מרווח מתוך המכירה, לא תוספת על העלות**. רווח גולמי בשקלים מוצג ללא מע״מ, בהנחת אותו שיעור מע״מ לקנייה ולמכירה. אין כאן חישוב רווח נקי, הוצאות חנות, פיקדון או מס הכנסה. מזינים עלות של יחידת המכירה (כולל הנחות ספק), לא ארגז. במבצע מערבב עם עלויות שונות יש להזין עלות שמייצגת את המוצרים באופן מתאים; אין חיבור אוטומטי למאגר.

אין עיגול ביניים של העלות. מחיר ההמלצה מעוגל למעלה לאגורה, או לסיומת .90 למעלה בלבד. המחיר הסופי ניתן לעריכה; מוצגת אזהרה כשהוא יורד מתחת ליעד. במסלול הידני המחיר המוזן כבר כולל מע״מ ולא נוסף עליו מע״מ נוסף. ברירת המחדל לשיעור היא 18%, וניתן לשנות גם ל־0% בהתאם למוצר.

מקור ברירת מחדל: רשות המסים, https://www.gov.il/he/pages/vat-history (יש לוודא שיעור מתאים בעת שינוי דין או סוג מוצר).

### ברקודים

האזור מקופל ורשות בלבד. ניתן להקליד, להשתמש בסורק קופה שמדמה מקלדת, או לפתוח מצלמה. הסריקה מוסיפה **מספר בלבד**, אינה מחפשת מוצר או מחיר. המצלמה לא מופעלת בכניסה לאפליקציה.

בדפדפן התומך מופעל BarcodeDetector. בדפדפנים אחרים נטענת בעצלות ZXing Browser 0.1.5 מ־jsDelivr; טעינה ראשונה זו דורשת אינטרנט. כשל או סירוב למצלמה אינם חוסמים הכנה ידנית. המצלמה נעצרת בסגירת המסך, במעבר לרקע או ביציאה מהדף. לא מתבצעת העלאת תמונות.

אפשר לצרף **דף CODE128 נפרד לקופה** עם המספרים המקוריים, כולל אפסים מובילים. הברקודים אינם מזהה של מבצע; יש להקים ולבדוק את המבצע בקופה. בדיקת מצלמה/מדפסת/סורק פיזיים מחייבת מכשירים אמיתיים; בדיקות הדפדפן אינן מחליפות זאת.

## שמירה ופרטיות

שמירה ב־localStorage במכשיר בלבד; כל שלט במפתח משלו למניעת דריסת רשימה מחלון אחר. אין סנכרון בין טלפונים. מחיקת נתוני האתר מוחקת את השלטים. כפתורי ייצוא/ייבוא JSON מספקים גיבוי ידני (הגיבוי כולל גם עלויות שהוזנו). ייבוא מוסיף עותקים ולא מוחק נתונים קיימים.

Service Worker מספק מעטפת לעבודה ללא חיבור אחרי טעינה ראשונה. לא נמחקים מטמונים של אפליקציות אחרות. אין skipWaiting שמחליף קוד באמצע עריכה.

## הדפסה ו־PDF

A4 עם שוליים פנימיים בטוחים. ה־PDF נכתב מקומית וכולל את הקנבסים של התצוגה, כ־150dpi, ללא תלות ברשת. PDF זה מבוסס תמונות ואינו כולל טקסט בר־בחירה. המחירים/הכותרות מסתגלים לרוחב הזמין. דפי חוץ ועמודי ברקודים יכולים להיות בכיוונים שונים באותו PDF.

בהדפסה יש לבחור A4, גודל בפועל/100% וללא כותרת/תחתית של הדפדפן. כאשר יש כיוונים שונים, מומלץ להדפיס את ה־PDF. פרטי חוקיות/תנאי מבצע ותוקף הם באחריות מי שמזין אותם; האפליקציה אינה מוסיפה טענות פרסומיות או תאריכים שלא הוזנו.

## פיתוח ובדיקות

ללא שלב build. GitHub Pages: ענף `main`, תיקיית `/ (root)`.

```sh
python3 -m http.server 8080
npm test
npm install --ignore-scripts
npx playwright install --with-deps chromium webkit
npm run test:browser
```

CI בודק חישובי מע״מ ומרווח, עיגול, קלט שגוי, פריסות, CODE128, שמירה, שבע תבניות, מסלולים ידניים/מחושבים, PDF וגלישה בנייד ב־Chromium וב־WebKit. צילומי מסך ו־PDF לדוגמה נשמרים ב־Actions artifacts למשך 7 ימים. הבדיקות אינן טוענות שבוצעה בדיקה במכשיר iPhone או במדפסת פיזית.
